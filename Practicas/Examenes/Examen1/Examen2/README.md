## Examen 2P
Este examen fue una prueba de recibir y transmitir comandos UART a la vez de implementar programación multihilos, ADC y PWM. Los pines usados fueron:
GPIO 26 para ADC - potenciómetro
GPIO 13 para led digital
GPIO 15 para led PWM
GPIO 16 para botón PULL-UP
GPIO 0 y 1 para TX - Rx UART
