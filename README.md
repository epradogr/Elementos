
# Repositorio de Laboratorio de Elementos Programables
En este repositorio subiré las prácticas que llevare a cabo durante el curso de elementos programables trabajando con un microcontrolador Raspberry Pi Pico 2. Dentro de cada práctica se incluirán evidencias tanto de simulación en Wokwi como físicas trabajando con el hardware además del código y documentación.
